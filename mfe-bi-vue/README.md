# Microfrontend de Inteligencia de Negocios y Dashboards (Vue 3)

- **Tecnología:** Vue 3 + Composition API + Webpack 5 Module Federation + Apache ECharts / Chart.js
- **Puerto por defecto:** 3003
- **Responsabilidad:**
  - Visualización de métricas ejecutivas: absorción de m², rotación de inventario.
  - Mapas de calor de demanda y precios promedio por zona geográfica.
  - Ranking de rendimiento de agentes y liquidación de comisiones.
  - Expone el componente federado `./BIDashboard`.
