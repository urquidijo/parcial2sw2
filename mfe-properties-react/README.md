# Microfrontend de Catálogo y Marketplace Inmobiliario (React)

- **Tecnología:** React 18 + Webpack 5 Module Federation + Mapbox / Leaflet
- **Puerto por defecto:** 3001
- **Responsabilidad:**
  - Explorador visual interactivo de propiedades con mapas georreferenciados.
  - Galerías de fotos, planos y recorridos virtuales 360°.
  - Filtros dinámicos en tiempo real (precio, m², dormitorios, tipo de propiedad).
  - Expone los módulos federados `./PropertyExplorer` y `./PropertyDetail`.
